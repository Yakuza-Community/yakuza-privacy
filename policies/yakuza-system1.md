# Privacy Policy — Yakuza System1

**Effective date:** September 2, 2026
**Operator/contact:** Yakuza Community — **yakuza.community@proton.me**

Yakuza System1 is a Discord bot for Yakuza Community servers. This policy applies only to this bot.

## Data we process

To provide bot features, we may process Discord user, server, channel, role, and message identifiers; usernames/display names; member join dates; role and reaction information; command and interaction inputs; leaderboard, XP, reminder, sticker, and feature-setting records. For enabled message-triggered features, we process the triggering message content. If a server enables the optional GPT feature, the relevant message content is sent to the configured AI provider to generate the requested response.

## Why we process it

We use this data only to provide and secure enabled bot features, including automated replies, roles, reminders, leaderboards, join-date records, community games/stickers, and optional AI responses. We do not sell personal data or use it for advertising.

## Sharing and storage

Discord provides the platform data required for the bot to operate. Feature records are stored in the bot's configured database. When optional AI or external game/image-search features are enabled, the specific request data needed for that feature may be sent to the configured provider. We do not share data with unrelated advertisers.

## Retention and deletion

We retain feature records only while they are needed to operate the server feature, maintain a leaderboard/history, or meet a legitimate operational/security need. A user or server administrator may request deletion of applicable bot data by contacting **yakuza.community@proton.me**. We will verify the request where necessary and delete data we control unless we must retain it for security, legal, or dispute-resolution reasons.

## Security and changes

We use reasonable technical and organizational measures to protect bot data. No service can guarantee absolute security. We may update this policy when bot features or legal requirements change; the current version will be published at this URL.
