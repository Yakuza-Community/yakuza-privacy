# Privacy Policy — Yakuza Games

**Effective date:** September 2, 2026
**Operator/contact:** Yakuza Community — **yakuza.community@proton.me**

Yakuza Games is a Discord bot for community game sessions, lobbies, player points, profiles, and leaderboards.

## Data we process

We process Discord user, server, channel, role, and message identifiers; usernames/display names; command inputs; game-lobby participation; scores, points, profiles, leaderboard entries; and server configuration/administrator records.

## Why we process it

We use this information only to run game sessions, identify participants, enforce server permissions, calculate and display scores/leaderboards, and maintain bot configuration. The bot reads message content only when a message begins with its configured command prefix. We do not sell personal data, advertise based on it, or read unrelated conversations for profiling.

## Storage, sharing, and retention

Game and configuration records are stored in the bot's configured database. Discord provides the platform data necessary for bot operation. We do not share data with unrelated advertisers. We keep records only while needed for game and leaderboard operations, security, or administration. A user or server administrator may request deletion of applicable bot data by contacting **yakuza.community@proton.me**.

## Security and changes

We use reasonable safeguards for bot data and may update this policy as the bot changes. The current version will be published at this URL.
