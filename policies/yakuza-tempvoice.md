# Privacy Policy — Yakuza TempVoice

**Effective date:** September 2, 2026
**Operator/contact:** Yakuza Community — **yakuza.community@proton.me**

Yakuza TempVoice creates and manages temporary Discord voice rooms.

## Data we process

We process Discord user, server, channel, and role identifiers; usernames/display names; voice-state changes; temporary-room ownership and access settings; command/interaction inputs; and operational audit records.

## Why we process it

We use this data only to create a temporary room when a member joins a configured creator channel, identify its owner, apply access controls, handle room-control commands, recover room state after restarts, and delete rooms when no longer needed. We do not read message content, sell personal data, or use data for advertising.

## Storage, sharing, and retention

Temporary-room and configuration records are stored in the bot's configured database. Discord provides the platform data required for the bot to operate. We retain data only while necessary for room management, operational recovery, security, or administration. Users or server administrators may request deletion of applicable bot data by contacting **yakuza.community@proton.me**.

## Security and changes

We use reasonable safeguards for bot data. We may update this policy when features change; the current version will remain available at this URL.
