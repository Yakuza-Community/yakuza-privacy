# Yakuza Tickets Privacy Policy

**Effective date:** September 2, 2026

**Operator/contact:** Yakuza Community — **yakuza.community@proton.me**

This policy applies to the Yakuza Tickets Discord application (the `Yakuza-System` codebase / Plex Tickets). It does not apply to Yakuza System1 or the other Yakuza applications.

## Data we process

To create and manage support tickets, we process Discord user, guild, channel, role, and message IDs; usernames/display names; ticket category and status; command, button, select-menu, and modal inputs; ticket participant and staff-claim records; messages and attachments sent within a ticket; transcript files; ratings/reviews; ticket, staff, and server statistics; and server configuration records.

Where enabled by a server administrator, the bot may also process invoice or payment reference data for PayPal, Stripe, or crypto-payment features, and ticket content submitted to the optional AI summary or auto-response feature.

## Why we process it

We use this information only to open, restrict access to, operate, archive, close, and delete support tickets; create and send transcripts; apply staff workflows and access controls; provide configured ratings, statistics, payment, and AI features; diagnose failures; and help server administrators manage their support process. We do not sell Discord data or use it for targeted advertising.

## Storage and sharing

Ticket and configuration records are stored in the bot's configured MongoDB database. Transcripts may be posted to Discord log channels selected by server administrators, stored locally when that option is enabled, or made available through the configured dashboard. Payment data is sent only to the payment provider selected by the server. When a server enables optional AI features, the relevant ticket content is sent to the configured AI provider. If the optional error-report upload setting is enabled, sanitized diagnostic logs may be sent to the configured paste service. We do not share data with unrelated advertisers.

## Retention and deletion

Ticket records and transcripts are retained only while needed for the configured ticket workflow, archive/history, security, payment/support administration, or dispute resolution. Server administrators control ticket closure, deletion, archiving, and Discord log-channel retention. Users and server administrators may request deletion of bot data associated with a Discord user or server ID by contacting **yakuza.community@proton.me**. We may verify the request and retain limited data where necessary for security, legal, fraud-prevention, or dispute-resolution purposes.

## Security and changes

We use reasonable technical and organizational safeguards to protect bot data. No service can guarantee absolute security. We may update this policy when the application's features or providers change; the current version will be published at this URL.

## Contact

Privacy questions and deletion requests: **yakuza.community@proton.me**
