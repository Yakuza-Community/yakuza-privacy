# Yakuza System Privacy Policy

**Effective date:** [September 1, 2026]

**Operator/contact:** [yakuza.community@proton.me]

This policy applies to the Yakuza System Discord application (application ID
`506148787362988033`). It does not automatically apply to other Yakuza applications.

## Data we process

Depending on which features a server administrator enables, the bot may process Discord user,
guild, channel, role, and message IDs; usernames/display names and current roles; member join,
leave, and update events; voice-state timestamps; aggregate voice/chat activity; command and
feature settings; temporary-role records; suggestions and their voting state; sticker/event
submissions; attachments and URLs; and message content needed by automatic replies/reactions,
event participation, member-invoked tools, and moderation logs.

The optional GPT feature processes the content of messages that invoke it and sends the prompt to
the configured API provider to generate a response. Yakuza System does not use Discord data to
train its own machine-learning models.

## Why we process it

We process this data only to provide requested bot functions, maintain persistent configuration
and aggregate leaderboards, enforce role-based access, operate community events, respond to
commands or configured triggers, diagnose failures, and help server administrators moderate their
server. We do not sell Discord data or use it for targeted advertising.

## Storage and sharing

Persistent feature data is stored in the operator's database. Moderation logs are sent to private
Discord channels selected by each server's administrators. Limited data is shared with service
providers only when necessary to operate the bot, such as database hosting and the configured AI
API for explicitly invoked GPT responses. Their processing is governed by their applicable terms
and privacy policies.

We do not intentionally archive every ordinary guild message in the off-platform database.
Feature-specific text, including submitted suggestions and administrator-configured automatic
reply text, may be retained while needed to provide that feature.

## Retention and security

We retain records only while they are needed to operate the applicable feature, meet legitimate
security requirements, or resolve abuse and support issues. Server administrators can remove
feature configuration and Discord-hosted log messages using the bot and Discord controls. The
operator restricts database access to authorized personnel and uses reasonable technical and
organizational safeguards.

## Requests and deletion

Users and server administrators may request access to or deletion of data associated with their
Discord user or server ID by contacting **[yakuza.community@proton.me]**. Include the relevant Discord
user/server ID so the operator can locate the records. The operator may ask the requester to
verify control of the relevant Discord account or server and will respond within a reasonable
period, subject to legal, security, and abuse-prevention obligations.

Users who do not want message-driven features to process new messages should contact their server
administrators about disabling the relevant feature or removing the bot. The current application
does not provide a universal per-user message-content opt-out, so this limitation must not be
misrepresented in Discord's review form.

## Children's privacy and changes

The bot is intended for people permitted to use Discord under Discord's own age requirements. We
may update this policy when the application's features or providers change. Material changes will
be reflected by updating the effective date on the publicly hosted version.
